# Ripple Voice <a href="README.md" style="float:right;font-size:0.5rem;font-weight:normal;color:inherit;">English</a>

Голосовой ввод для Windows. Нажал клавишу — сказал — текст вставлен. Your voice, in flow.

![Ripple Voice](topic.gif)

## Зачем это нужно

Windows имеет встроенный голосовой ввод (Win+H), но он:
- Отправляет голос в облако Microsoft
- Медленный и неточный
- Не работает оффлайн
- Неудобный интерфейс

**Ripple Voice** делает то же самое, но:
- **Полностью оффлайн** — модель работает на вашем компьютере
- **Быстро** — CUDA GPU ускоряет распознавание в 10+ раз
- **Приватно** — голос никогда не покидает ваш компьютер
- **Красиво** — анимированный HUD показывает что происходит

## Как это работает

![Анимация работы](animation.gif)

1. **Нажмите горячую клавишу** — появляется HUD, начинается запись
2. **Говорите** — бары пульсируют в ритм голоса, круг показывает громкость
3. **Отпустите клавишу** — запись останавливается, текст распознаётся
4. **Текст вставляется** в активное поле (Блокнот, Word, браузер — куда угодно)

Всё. Никаких окон, никаких кнопок — просто говорите и текст появляется.

## Установка

```powershell
git clone https://github.com/Ap3x0s/Ripple-Voice.git
cd Ripple-Voice
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```powershell
# Через venv (рекомендуется)
Ripple Voice.bat

# Или вручную
.venv\Scripts\python.exe main.py
```

При первом запуске модель скачивается автоматически (~1.5 ГБ). Далее работает оффлайн.

## GPU (CUDA)

При наличии NVIDIA GPU приложение автоматически использует CUDA для ускорения распознавания:

| Устройство | Скорость (medium) | Качество |
|------------|-------------------|----------|
| CPU (int8) | ~8-12 сек | Отличное |
| CUDA (float16) | ~0.5-1 сек | Отличное |

Выбор устройства: **Настройки → Устройство → CUDA (GPU) / CPU / Auto**

Требования для CUDA:
- NVIDIA GPU с поддержкой CUDA (GTX 10xx и новее)
- Установленные NVIDIA драйверы
- PyTorch с CUDA (входит в установку)

Если возникает ошибка `cublas64_12.dll not found`, установите дополнительно:
```powershell
pip install nvidia-cublas-cu12
```

## Использование

| Действие | Результат |
|----------|-----------|
| **Горячая клавиша (зажать)** | Начать запись |
| **Горячая клавиша (отпустить)** | Вставить текст |
| **Escape** | Отмена записи |
| **ПКМ по иконке в трее** | Настройки / Выход |

## Настройки

ПКМ по иконке в трее → **Настройки**. В окне настроек можно менять:

- Горячую клавишу и режим записи (зажатие / переключение)
- Язык распознавания речи
- Устройство (GPU CUDA / CPU)
- Модель Whisper (tiny → large-v3)
- Тему HUD интерфейса
- Язык интерфейса (Русский / English)
- Пунктуацию

Все изменения применяются сразу после нажатия «Сохранить» — перезапуск не нужен. Настройки хранятся в `~/Documents/ripple-voice/settings.json`.

## Темы HUD

| Тема | Стиль |
|------|-------|
| `google` | Мягкий, минималистичный |
| `google_v2` | Премиум с физикой пружин |
| `hybrid_v2` | ★ Основная — бары + таймер + круг громкости |
| `vercel` | Острый, кибер-стиль |

## Модели Whisper

| Модель | Размер | Скорость (CPU) | Скорость (CUDA) | Качество |
|--------|--------|----------------|-----------------|----------|
| `tiny` | 75 МБ | Быстро | Мгновенно | Среднее |
| `base` | 150 МБ | Нормально | Мгновенно | Хорошее |
| `small` | 500 МБ | Нормально | Мгновенно | Отличное |
| `medium` | 1.5 ГБ | Медленно | ~1 сек | Отличное |
| `large-v3` | 3 ГБ | Очень медленно | ~1-2 сек | Максимальное |

Рекомендация: `medium` + CUDA — лучший баланс скорость/качество.

## Структура проекта

```
Ripple-Voice/
├── main.py              # Точка входа, связывает всё вместе
├── audio_recorder.py    # Запись звука с микрофона
├── transcriber.py       # Распознавание речи (faster-whisper)
├── text_inserter.py     # Вставка текста в активное окно
├── hotkey_manager.py    # Перехват горячих клавиш
├── settings.py          # Управление настройками
├── settings_window.py   # Окно настроек (PyQt6)
├── stats.py             # Статистика сессий
├── history.py           # История распознаваний
├── hud_window.py        # Диспетчер тем HUD
├── hud_hybrid_v2.py     # Основная тема интерфейса
├── hud_google.py        # Тема Google
├── hud_google_v2.py     # Тема Google v2
├── hud_vercel.py        # Тема Vercel
├── tray_icon.py         # Иконка в системном трее
├── requirements.txt     # Зависимости Python
├── Ripple Voice.bat     # Быстрый запуск (Windows)
└── assets/              # Иконки и логотипы
```

## Требования

- Windows 10/11
- Python 3.10+
- Микрофон
- NVIDIA GPU (опционально, для CUDA ускорения)

## Приватность

- Голос обрабатывается **локально** на вашем компьютере
- Никакие данные не отправляются в интернет
- Модель скачивается один раз при первом запуске
- История и настройки хранятся только у вас: `~/Documents/ripple-voice/`
